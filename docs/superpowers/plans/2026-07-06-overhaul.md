# CommanderPlayPad Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate CommanderPlayPad to Svelte 5 runes with a central game-state module, fix all known issues, add localStorage persistence, poison counters, monarch tracking, and a clean & minimal UI refresh.

**Architecture:** A `src/lib/game.svelte.js` module holds all game state in a single `$state` object with mutation functions; components become thin views. One timestamp-based ticker drives all clocks. Death is computed (`isDead`), never stored. Spec: `docs/superpowers/specs/2026-07-06-overhaul-design.md`.

**Tech Stack:** Svelte ^5.33 (runes), SvelteKit ^2.21, Vite 6. No new runtime dependencies.

## Global Constraints

- **Branching:** NEVER commit to `master`. One branch per task (name given in each task); the owner merges each branch when satisfied. Each task assumes the previous task's branch has been merged to `master`; if it hasn't, branch from the previous task's branch instead.
- **Offline:** the app must work with no network (shared iPad at a game table). No CDN links, no external fonts/icons.
- **Scaling:** keep the fixed 2048×1536 canvas + `scale(x, y)` transform in `+page.svelte`. Do not convert to responsive units.
- **Testing:** no test framework exists and none is added. Every task ends with a manual verification checklist run via `npm run dev` in a browser (device-emulate a 4:3 viewport, e.g. 1024×768). Run `npm install` once before Task 1 if `node_modules` is missing.
- **Svelte idioms:** after Task 1, only runes (`$state`, `$derived`, `$props`, `$effect`) — no `createEventDispatcher`, no `svelte/store` in app code, callback props for child→parent notification.
- **Game rules:** commander damage clamps 0–21; poison clamps 0–10 and does NOT change life; dead = life ≤ 0 OR poison ≥ 10 OR time = 0.
- **Settings** (starting life 40 / starting time 23 min) take effect on Restart only.

```js
export const COMMANDER_DAMAGE_LETHAL = 21;
export const POISON_LETHAL = 10;

const LIFECHANGE_FADEOUT_MS = 2000;
const LIFECHANGE_SHOW_MS = 8000;

const DEFAULT_SETTINGS = { startingLife: 40, startingTimeMinutes: 23 };

const PLAYER_COLORS = [
  { color: "#3d5a80", colorSecondary: "#2b3f59" },
  { color: "#a84a4a", colorSecondary: "#7e3838" },
  { color: "#9a983f", colorSecondary: "#605e27" },
  { color: "#4b9d44", colorSecondary: "#2f5d2a" },
];

function createPlayer(index, settings) {
  return {
    name: `Player ${index + 1}`,
    ...PLAYER_COLORS[index],
    life: settings.startingLife,
    timeRemainingSeconds: settings.startingTimeMinutes * 60,
    poison: 0,
    commanderDamageGiven: [0, 0, 0, 0],
    lifeHistory: [{ lifeChange: 0, newLifeTotal: settings.startingLife }],
    pendingLifeChange: 0,
    lifeChangePhase: "hidden",
  };
}

export const game = $state({
  settings: { ...DEFAULT_SETTINGS },
  players: [0, 1, 2, 3].map((i) => createPlayer(i, DEFAULT_SETTINGS)),
  activePlayerIndex: -1,
  monarchIndex: -1,
});

export function isDead(player) {
  return (
    player.life <= 0 ||
    player.poison >= POISON_LETHAL ||
    player.timeRemainingSeconds <= 0
  );
}

/* ---------- life & history ---------- */

const lifeChangeShowTimeouts = [null, null, null, null];
const lifeChangeFadeTimeouts = [null, null, null, null];

export function addToLife(index, delta) {
  const player = game.players[index];
  player.life += delta;
  player.pendingLifeChange += delta;
  player.lifeChangePhase = "shown";

  clearTimeout(lifeChangeShowTimeouts[index]);
  clearTimeout(lifeChangeFadeTimeouts[index]);
  lifeChangeShowTimeouts[index] = setTimeout(() => {
    player.lifeChangePhase = "fading";
    if (player.pendingLifeChange !== 0) {
      player.lifeHistory.push({
        lifeChange: player.pendingLifeChange,
        newLifeTotal: player.life,
      });
    }
    lifeChangeFadeTimeouts[index] = setTimeout(() => {
      player.pendingLifeChange = 0;
      player.lifeChangePhase = "hidden";
    }, LIFECHANGE_FADEOUT_MS);
  }, LIFECHANGE_SHOW_MS);

  if (isDead(player) && game.activePlayerIndex === index) pauseGame();
}

/* ---------- commander damage ---------- */

export function addCommanderDamage(fromIndex, toIndex, delta) {
  const given = game.players[fromIndex].commanderDamageGiven;
  const next = Math.max(0, Math.min(COMMANDER_DAMAGE_LETHAL, given[toIndex] + delta));
  const applied = next - given[toIndex];
  if (applied === 0) return;
  given[toIndex] = next;
  addToLife(toIndex, -applied);
}

/* ---------- poison & monarch (UI in later tasks) ---------- */

export function addPoison(index, delta) {
  const player = game.players[index];
  player.poison = Math.max(0, Math.min(POISON_LETHAL, player.poison + delta));
  if (isDead(player) && game.activePlayerIndex === index) pauseGame();
}

export function setMonarch(index) {
  game.monarchIndex = game.monarchIndex === index ? -1 : index;
}

/* ---------- clock (single timestamp-based ticker) ---------- */

let tickHandle = null;
let turnStartMs = 0;
let timeAtTurnStartSeconds = 0;

function tick() {
  const index = game.activePlayerIndex;
  if (index === -1) return;
  const player = game.players[index];
  const elapsed = Math.floor((Date.now() - turnStartMs) / 1000);
  player.timeRemainingSeconds = Math.max(0, timeAtTurnStartSeconds - elapsed);
  if (player.timeRemainingSeconds === 0) pauseGame();
}

export function pauseGame() {
  if (tickHandle) {
    clearInterval(tickHandle);
    tickHandle = null;
  }
  if (game.activePlayerIndex !== -1) {
    const index = game.activePlayerIndex;
    const player = game.players[index];
    const elapsed = Math.floor((Date.now() - turnStartMs) / 1000);
    player.timeRemainingSeconds = Math.max(0, timeAtTurnStartSeconds - elapsed);
    game.activePlayerIndex = -1;
  }
}

export function setActivePlayer(index) {
  if (game.activePlayerIndex === index) {
    pauseGame();
    return;
  }
  pauseGame();
  const player = game.players[index];
  if (!player || isDead(player)) return;
  game.activePlayerIndex = index;
  turnStartMs = Date.now();
  timeAtTurnStartSeconds = player.timeRemainingSeconds;
  tickHandle = setInterval(tick, 250);
}

/* ---------- names & restart ---------- */

export function setPlayerName(index, newName) {
  const trimmed = newName.trim();
  if (trimmed === "") return;
  game.players[index].name = trimmed;
}

export function restartGame() {
  pauseGame();
  for (let i = 0; i < game.players.length; i++) {
    clearTimeout(lifeChangeShowTimeouts[i]);
    clearTimeout(lifeChangeFadeTimeouts[i]);
  }
  game.monarchIndex = -1;
  game.players = game.players.map((p, i) => ({
    ...createPlayer(i, game.settings),
    name: p.name,
  }));
}
```

### Task 3: localStorage persistence

**Branch:** `feat/persistence`

**Files:**

**Interfaces:**
- Consumes: `game` object shape from Task 1.
- Produces: `loadSavedState(): boolean` (true = a saved game was restored), `saveGame(): void`. Storage keys `commanderplaypad.game.v1` and `commanderplaypad.settings.v1`.

- [ ] **Step 1: Create the branch**

```bash
git checkout master && git checkout -b feat/persistence
```

- [ ] **Step 2: Create `src/lib/persistence.svelte.js`**

```js
import { game } from "./game.svelte.js";

const GAME_KEY = "commanderplaypad.game.v1";
const SETTINGS_KEY = "commanderplaypad.settings.v1";

export function loadSavedState() {
  try {
    const settingsJson = localStorage.getItem(SETTINGS_KEY);
    if (settingsJson) {
      Object.assign(game.settings, JSON.parse(settingsJson));
    }
    const gameJson = localStorage.getItem(GAME_KEY);
    if (!gameJson) return false;
    const saved = JSON.parse(gameJson);
    game.players = saved.players.map((p) => ({
      ...p,
      // never restore a mid-fade bubble; its timeout died with the old page
      pendingLifeChange: 0,
      lifeChangePhase: "hidden",
    }));
    game.monarchIndex = saved.monarchIndex ?? -1;
    // resume paused: no clock runs after a reload, tap a player to continue
    game.activePlayerIndex = -1;
    return true;
  } catch {
    return false;
  }
}

export function saveGame() {
  localStorage.setItem(
    GAME_KEY,
    JSON.stringify({ players: game.players, monarchIndex: game.monarchIndex })
  );
  localStorage.setItem(SETTINGS_KEY, JSON.stringify(game.settings));
}
```

- [ ] **Step 3: Wire into `src/routes/+page.svelte`**

Add to imports:

```js
    import { loadSavedState, saveGame } from "$lib/persistence.svelte.js";
```

Change `onMount` so random names only apply to a fresh game, and add a save effect after it:

```js
    onMount(() => {
        const restored = loadSavedState();
        if (!restored) {
            setRandomPlayerNames();
        }
        scaleToWindow();
        window.addEventListener("resize", scaleToWindow);
        return () => window.removeEventListener("resize", scaleToWindow);
    });

    $effect(() => {
        saveGame(); // JSON.stringify reads all game state -> effect reruns on any change
    });
```

1. Fresh load (DevTools → Application → clear localStorage first): random names, 40 life, 23:00 — and `commanderplaypad.game.v1` + `commanderplaypad.settings.v1` appear in localStorage.
2. Change life totals, add commander damage, rename a player, run a clock for ~30s, then **reload**: everything restored exactly, no clock running (tap the player to resume their clock from where it stopped).
3. Restart via settings → reload → fresh game persists (names kept, 40/23:00) — no ghost of the old game.
4. Change starting life to 30, Restart, reload → still 30 (settings survive reloads and games).
5. Corrupt-save fallback: in DevTools console run `localStorage.setItem("commanderplaypad.game.v1", "garbage")`, reload → app starts a fresh game instead of crashing.
